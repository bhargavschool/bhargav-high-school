BHARGAV HIGH SCHOOL WEBSITE
=============================

Files:
- index.html
- style.css
- script.js
- images/logo.jpg
- images/building.jpg
- images/events/  (add future event photos here)

HOW TO VIEW:
1. Keep the folder structure unchanged.
2. Double-click index.html.
3. The website will open in your browser.

HOW TO ADD EVENT PHOTOS:
Put event images inside images/events/.
For a polished gallery, edit the gallery cards in index.html and add your image paths.

HOW TO PUBLISH FOR FREE:
The website is a static HTML/CSS/JavaScript site and can be hosted on GitHub Pages.
You can later connect a custom domain if you decide to buy one.
